# User Preferences

- **Eficiência de Contexto:** Sempre consulte `.agents/CURRENT.md` antes de qualquer busca.
- **Edições Cirúrgicas:** Use `replace_file_content` com intervalos exatos de linhas.
- **Comentários Mínimos:** Código autoexplicativo através de nomenclatura semântica; comentários apenas para quirks e restrições técnicas (como o tipo geography PostGIS).
- **Tipagem Estrita:** Uso de `type` para DTOs, schemas estritos no TypeScript e proibição de `any`.
- **Rastreabilidade:** Sempre atualizar `CURRENT.md` e registrar entradas em `COMMITS.md`.
